ollama pull llama2:7b

python main.py -input input/profiles -output output/profiles -jd input/job_description.txt

Mandatory core task - no target job, just polish each candidate's own facts (omit -jd):
python main.py -input input/profiles -output output/core

python main.py -input input/profiles -output output/profiles -jd input/job_description.txt -review
